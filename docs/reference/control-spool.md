# Control spool

Generated by `scripts/gen_reference.py` from the pydantic models in `src/mc_helper/entities/`. Do not edit by hand; run `uv run python scripts/gen_reference.py --write`. A test fails when this file is stale.

The control folder holds `requests/`, `results/` and `status.json`. The supervisor creates `requests/` and `results/`; the app never does. Both directories must be writable by the app's uid (it adds requests and deletes old results), and `status.json` and the result files must be readable by it.

## Status: `status.json` (written by the supervisor)

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| `online` | array of string | yes | none |
| `allowlist` | array of string | yes | none |
| `server_version` | string | yes | maxLength: `50` |
| `last_backup` | string (date-time) or null | yes | none |
| `last_backup_ok` | boolean | yes | none |
| `started` | string (date-time) | yes | none |
| `updated` | string (date-time) | yes | none |

Entries of `online` and `allowlist` that are not strings or are over 100 characters are dropped, and each list is cut to 500 entries. `server_version` is cut to 50 characters. A time without a zone is read as UTC. The server counts as not answering when `updated` is more than 60 seconds away from now (setting `STATUS_MAX_AGE_SECONDS`).
