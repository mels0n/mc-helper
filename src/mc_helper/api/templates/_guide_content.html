Step 1 for everyone

Get ready

  1. Install Minecraft. Use Minecraft (Bedrock Edition), the one on Switch, phones, tablets, Windows, Xbox and PlayStation. Sign in with a free Microsoft account. Your Xbox gamertag is your name in the game.
  2. Send your gamertag to the person who runs this server. They add you to the friends list. Only people on the list can join.
  3. Check your device. Mac computers and Minecraft Java Edition cannot join this server.

Step 2

Nintendo Switch, Switch 2, Xbox and PlayStation

Consoles cannot type in a server address, so the server shows up in your Friends tab instead.

  1. On a Switch or Switch 2, you need Nintendo Switch Online to play online.
  2. Open Minecraft and choose Play, then Friends, then Add Friend.
  3. Search for {{ broadcast }} and send a friend request.
  4. Wait about a minute. The server appears under the Friends tab as a joinable cross-platform friend.
  5. Tap it, then choose Join.

Xbox and PlayStation use the same steps as the Switch.

Step 2

iPhone, iPad, Android, Windows PC and Chromebook

  1. Open Minecraft and choose Play, then Servers.
  2. Scroll down and choose Add Server.
  3. Fill in the boxes:
    • Server Name: anything you like
    • Server Address: {{ address }}
    • Port: {{ port }}
  4. Choose Save, then tap the server to join.

The Friends tab way (add {{ broadcast }} as a friend) works on these devices too.

For parents

Quick checklist

  • In the Microsoft family settings for the child account (family.microsoft.com or the Xbox Family Settings app), allow join multiplayer games.
  • Allow play with people outside of Xbox (cross-network play).
  • Allow adding friends.
  • On Nintendo, parental controls must allow communicating with others for Minecraft.
  • A Switch needs a Nintendo Switch Online membership to play online.
  • Changes to Microsoft settings can take a few hours to apply.

Stuck?

Troubleshooting

It says I am not on the friends list
Ask the person who runs the server to add your gamertag.
I cannot connect
Ask a parent to check the family settings in the checklist above.
The server does not show in my Friends tab
Make sure the {{ broadcast }} friend request was accepted, then close Minecraft and open it again.
